# Scale V1.4.7 — October 15, 2026

**Release type:** Scale-only ESP32-S3 firmware release. The e-paper display and
Wi-Fi touchscreen Production channels remain at V1.4.0. TouchPour V0.1.11 is
a separate manually flashed project and is not part of this OTA release.

## Changes

- Wider HX711 stability hysteresis: Stable at or below 0.150 lb rolling
  spread, Settling above 0.300 lb; three-sample median window unchanged.
  Corrects e-paper staying on an old serving count when jitter was ~0.076 lb.
- Offline factory calibration directly from the Scale captive setup portal,
  without first connecting to the customer's Wi-Fi.
- Signed-channel OTA manifest verification for Scale and e-paper updates.
- E-paper current-version guard to avoid repeatedly offering the installed
  or an older display firmware.
- BLE display check-in, touch wake, reboot and sleep diagnostics surfaced
  in the Scale Debug/support interface.
- Existing Scale configuration, NVS calibration and paired displays remain
  supported.

`tools/promote_dev_to_production.py --version V1.4.7 --device scale` from
the **exact signed Dev binary**, not from a separately compiled image.
The promotion tool reported eight passing signature, identity, and exact-byte
provenance checks, with no warnings or failures. Before publication, locally
rerun the full release checker against the final staged files.

## Hardware validation and explicit exception

- ESP-IDF 6.0.1 build and host regression suite passed for the Scale source.
- Hardware checks confirmed Scale measurement, stability and e-paper updates
  after the stability threshold adjustment.
- **Not exercised:** over-the-air installation from a Scale with older firmware
  to V1.4.7. All available physical scales were already running V1.4.7.
  The decision to release without this test must be accepted as a documented
  validation exception; do not record it as a passed OTA installation test.
- After publishing, check that older-version devices (when available) discover
  and successfully install the update while preserving settings and calibration.

## Channels and retention

- Scale: Dev, Production and Beta V1.4.7 once published.
- E-paper and Wi-Fi touchscreen: Production/Beta V1.4.0 unchanged.
- The V1.4.0 Scale binary remains available under its original commit-named
  filename as the previous release; **do not delete it**.
- Signed manifests identify the active firmware; changing the manifest must
  accompany the matching signed artifact and previous binary retention.

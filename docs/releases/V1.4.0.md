# V1.4.0 - September 25, 2026

V1.4.0 is the current coordinated Production baseline for the Keg Scale system:
the ESP32-S3 Scale, LILYGO T5 V2.3.1 e-paper display, and Waveshare
ESP32-S3-Touch-LCD-4B Wi-Fi touchscreen.

## Release artifacts

The authoritative artifact inventories are:

- `V1.4.0-scale-dev-production-artifacts.json`
- `V1.4.0-display-dev-production-artifacts.json`
- `V1.4.0-touchscreen-dev-production-artifacts.json`

Production binaries are device-specific and must not be interchanged.

## Channel state

Production, Beta, and Dev are supported signed channels.

- **Production** serves the coordinated V1.4.0 release.
- **Beta** normally mirrors the exact Production binary bytes for all three
  devices and can later be advanced with exact signed Dev bytes for coordinated
  release-candidate testing.
- **Dev** may run newer validation/hardening firmware than Production.

On September 29, 2026, the three Beta feeds were synchronized to exact V1.4.0
Production bytes and the local release checker completed with **24 pass,
0 warning, 0 failure** across Dev/Beta/Production.

## OTA trust

Detached ECDSA P-256/SHA-256 manifest signatures were added after the V1.4.0
application binaries were published. This hardened the release metadata without
rebuilding or changing the V1.4.0 Production binaries.

Production uses a separate Production signing key. Beta uses the Dev signing
trust domain so release candidates can be tested without exposing Production
signing authority. Scale authenticates both its own feed and the e-paper feed;
Touch authenticates its feed directly.

## Post-release development

Later V1.4.x Dev builds are hardening/validation increments and are not
Production until explicitly promoted through the signed local release process.
At the September 29 documentation checkpoint those Dev builds were Scale V1.4.4,
e-paper V1.4.4, and Touch V1.4.2.

## Update order

Update the Scale first. Then update the e-paper display and Wi-Fi Touch Display.
The e-paper update is coordinated by the Scale over the authenticated BLE bond;
Touch downloads its own signed-channel update over Wi-Fi.

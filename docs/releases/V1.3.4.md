# V1.3.4 - September 23, 2026

This release synchronizes the Scale, e-paper display, and Wi-Fi Touch Display
across dev and production. Protocol compatibility remains version 1.

## Changes

- Scale webpage: Dashboard and Glass views, compact phone layout, serving-size
  vessels (12 oz can, 16 oz pint, 20 oz cup, 32 oz crowler, 64 oz growler), and a
  remembered browser view preference.
- Settings: fixed Keg & scale, Displays, Network & integrations, and System
  categories. Status polling no longer moves forms; navigation preserves drafts.
- Display setup: independent guided pairing, minimal unpaired controls, e-paper
  USB reminder, Touch countdown/cancel, and no home-view controls during pairing.
- Removed guided e-paper touch calibration, including interrupted-wizard resume.
  Default sensitivity is 1%; existing saved values remain unchanged and adjustable.
  Load-cell tare and weight calibration remain available.
- Scale sensor failures invalidate stale cached readings; recovery starts a fresh
  filter window. Failed tare/calibration saves preserve the live configuration.
- OTA/crypto hardening: authenticated display update approval coverage, ephemeral
  key cleanup on malformed agreement input, and mirrored protocol consistency gate.
- Regression suites cover sensor/filter/calibration failures, pairing/reconnect,
  lost acknowledgements, OTA failures, and e-paper wake/refresh state.
- OTA manifest discovery uses deterministic GitHub Contents API URLs.

## Updating

Use the matching device feed: firmware/ for Scale, display/ for e-paper, and
 touchscreen/ for Touch. All three report V1.3.4. Update the Scale first, then the
 displays. Refresh the browser after the Scale update. No factory reset is needed.

Existing Wi-Fi, pairings, profiles, calibration, and sensitivity remain saved.
Set sensitivity to 1 under Settings > Displays if an existing installation should
use the new default; upgrading does not overwrite a custom saved value.

## Validation and remaining work

Local host suites and browser layout checks cover this release. All three images
are built with ESP-IDF 6.0.1 before publication; manifests record binary size,
SHA-256, hardware target, source commit, and channel. Earlier builds of these
changes were flashed locally to Scale COM8, e-paper COM9, and Touch COM14; this
is not a claim that every hardware acceptance scenario passed.

Remaining checks include long-duration battery/radio behavior, power-loss OTA
rollback, and Touch discovery callback lifetime. E-paper command delivery is not
an end-to-end completion acknowledgement. See the regression/acceptance documents
for the detailed limits. Beta is not changed by this release.
